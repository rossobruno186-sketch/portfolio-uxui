## Declaración de uso de herramientas (IA y CDN)
* **Tailwind CSS CDN:** Se utilizó por eficiencia en despliegue estático para mantener el repositorio ágil sin entornos Node.js complejos.
* **Asistencia de IA:** Se empleó inteligencia artificial para la ideación conceptual y maquetación base, con revisión y refactorización manual posterior para asegurar cumplimiento estricto de accesibilidad WCAG 2.2, semántica HTML y responsividad en breakpoints (375px, 768px, 1280px).
